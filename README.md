# meu-primeiro-projeto

Meu primeiro projeto no GitHub — um espaço para aprender e experimentar.

## Sobre

Este repositório foi criado para explorar o fluxo de trabalho com Git e GitHub:
criar branches, fazer commits e abrir Pull Requests.

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/gabas13-coder/meu-primeiro-projeto.git
   ```
2. Entre na pasta:
   ```bash
   cd meu-primeiro-projeto
   ```
3. Faça suas alterações e crie um Pull Request!

## Contribuindo

Contribuições são bem-vindas. Abra uma issue ou envie um PR com suas sugestões.
